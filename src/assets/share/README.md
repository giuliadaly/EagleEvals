# Social preview assets

DM Sans and Patrick Hand are the same fonts used by the site. Source fonts and licenses came from the Google Fonts repository on September 8, 2026:

- https://github.com/google/fonts/tree/main/ofl/dmsans
- https://github.com/google/fonts/tree/main/ofl/patrickhand

The DM Sans variable font was instantiated at optical size 24 with weights 400 and 600. Fonts were subset to Latin and Latin Extended characters plus general punctuation for small, self-contained image rendering. License files are included.

The wing PNG is a lossless format conversion of the existing Blender-rendered `public/brand/wing-sculptural.webp`, for the image renderer. Sharing images do not fetch fonts or artwork from external services at request time.
