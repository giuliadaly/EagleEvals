# EagleEvals brand assets

The approved direction combines Field notes copy, DM Sans with Patrick Hand accents, maroon `#68182b`, gold `#e6bf58`, and warm paper `#f4f3ee`.

The wing-shaped E is the primary mark. The homepage uses a sculptural Blender render; the header and favicon use its flat three-feather counterpart. The small independence note is plain text outside the homepage link, 9px with a 7px gap beneath the wordmark.

The mascot stays perched. Clicking it plays a two-second stretch once, then returns to the perch. The sprite is fetched only on interaction; reduced-motion users keep the still image. There is no WebGL runtime or animation dependency.

`perched-eagle.blend` contains the editable Blender model, lights, camera, and 48-frame stretch at 24 fps. The render camera and lighting stay fixed. The sprite in `public/brand/eagle-stretch.webp` is eight columns by six rows of 384px frames, in reading order. `eagle-perched.webp` is the matching first frame. Both have transparent backgrounds.

Other web assets are `wing-sculptural.webp` and `paperclip.webp`. All model geometry was created for this project in Blender. No Boston College seal or official athletics logo is used.
